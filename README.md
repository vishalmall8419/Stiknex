## 📖 About Stiknex

Stiknex is a modern productivity web application designed to help users organize ideas, write notes, manage daily tasks, and use essential utilities from one clean and responsive workspace.

Instead of switching between multiple applications, Stiknex provides everything in one place including Sticky Notes, Notebook, Calculators, Converters, and other productivity tools.

The application is built with simplicity, speed, privacy, and usability in mind.

# ⚙ Installation

Clone the repository

```bash
git clone https://github.com/vishalmall8419/Stiknex.git
```

Go to project directory

```bash
cd Stiknex
```

Install frontend dependencies

```bash
npm install
```

Install backend dependencies

```bash
cd server
npm install
```

---

# ▶ Run Frontend

```bash
npm run dev
```

---

# ▶ Run Backend

```bash
npm start
```

---

# 🔑 Environment Variables

Create a `.env` file inside the `server` folder.

```env
RAZORPAY_KEY_ID=YOUR_KEY_ID
RAZORPAY_KEY_SECRET=YOUR_SECRET_KEY
PORT=5000
```

Frontend (Vite)

```env
VITE_RAZORPAY_KEY_ID=YOUR_KEY_ID
```
